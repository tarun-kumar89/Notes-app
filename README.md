# 📝 Notes App (React)

A simple and responsive Notes App built using React. This app allows users to create, edit, and delete notes easily.

---

## 🚀 Features

- ➕ Add new notes
- 📝 Edit existing notes
- ❌ Delete notes
- 💾 Data stored in local storage (optional)
- 📱 Responsive UI

---

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3 / Tailwind CSS (if used)
